# Kata-Kata — Blog Template

Kata-Kata adalah template blog modern berbasis HTML dan CSS.

Template ini dapat digunakan untuk:

- Blog pribadi.
- Blog teknologi.
- Blog bisnis.
- Blog sekolah.
- Dokumentasi project.
- Website artikel sederhana.

## Live Demo

https://danielsitompul899-blip.github.io/blog-template/

## Fitur

- Tampilan responsive.
- Hero section.
- Daftar artikel.
- Kategori artikel.
- Section tentang blog.
- Section kontak.
- Tombol kembali ke portfolio.
- Struktur sederhana dan mudah diedit.

## Teknologi

- HTML5.
- CSS3.
- GitHub Pages.
